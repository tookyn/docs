# Tookyn Docs

Static documentation site for Tookyn.

Public URL: <https://docs.tookyn.com>

## Local preview

Open `public/index.html` in a browser, or serve the folder with any static file server.

## Publish

The production site is published with Cloudflare Pages Direct Upload from the `public/` directory.

Deployment fallback: <https://tookyn-docs.pages.dev>
